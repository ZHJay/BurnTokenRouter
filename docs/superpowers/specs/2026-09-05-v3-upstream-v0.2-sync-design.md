# v3 Sync with Upstream v0.2 Design

## Context

Local and fork main are at d45135d87. Fetched upstream main is b1748c4ea;
both main refs are 379 commits behind and can fast-forward. The v3 branch is
at 2f7b56336 with 27 branch commits. Upstream changed 132 frontend files since
the shared base; 44 overlap v3. The worktree has no tracked changes but many
user-owned untracked duplicate files ending in 2 or 3; they remain untouched.

## Goals

- Fast-forward local main to b1748c4ea and push it normally to origin/main.
- Rebase v3 linearly onto that commit, retaining all upstream behavior.
- Preserve the Apple design system, GlobalNav, landing page, command palette,
  model-plaza cards/table toggle, chart theme, dark mode, and responsiveness.
- Expose and style every new upstream user-facing feature in the v3 system.
- Verify focused and full tests, typecheck, build, backend conflicts, and UI.
- Update remote v3 only after verification with an explicit force-with-lease.

## Non-goals

- No unrelated redesign, new dependency, abstraction layer, or second UI kit.
- No upstream remote mutation or unconditional force push.
- No deletion, rename, edit, move, or ignore rule for duplicate untracked files.

## History and Safety

Record safety refs for local and fetched remote v3 tips. Create a new backup
branch. Fast-forward main and push it. Then return to v3 and use a standard
linear rebase onto updated main, dropping obsolete upstream-sync merge commits.
Upstream owns behavior, API contracts, fields, routes, and tests. V3 owns
layout, navigation, design tokens, and responsive presentation.

Abort if an untracked path would be overwritten. If verification fails, do not
push v3. If its remote lease changes, fetch and reassess instead of overriding.

## Required Feature Coverage

- Plugin management: retain API, route, flag, locale, and PluginsView; add the
  gated admin entry to GlobalNav/navItems because AppSidebar stays deleted.
- Codex: retain API-key authentication, routed catalogs and cache isolation,
  capabilities, attribution headers, and the expanded Use Key guidance.
- Groups: retain OpenAI Fast/free-Fast, per-model reasoning mappings, and the
  deny-or-downgrade effort ceiling controls in the v3 field hierarchy.
- Usage: retain account priority, requested effort, native compaction kind,
  CN/Ollama windows, unified thresholds, and mobile table behavior.
- Pricing: retain weekday time pricing, IO/cache multipliers, DeepSeek rates,
  long-context tiers, and stacking explanations in card and table views.
- Accounts and operations: retain automatic reset-card thresholds, OpenAI
  refresh-token reauthorization, Zhipu team quota, public-group restrictions,
  IPv6 proxies, strict local dates, payment currency, OAuth promo codes, and
  expanded Ops error details.

## Conflict Rules

- Keep the meaningful gitignore union without hiding duplicate files.
- Preserve both fork version suffixes and upstream update behavior.
- Keep AppSidebar deleted and port its new plugin item to v3 navigation.
- Combine upstream CN quota/usage semantics with v3 visual classes.
- Combine upstream pricing semantics with v3 model-plaza presentation.
- Keep the locale-key union without shadowed duplicates.
- Preserve upstream registration/payment behavior inside v3 layouts.
- Never remove or weaken tests merely to finish conflict resolution.

Auto-merged code receives the same review as explicit conflicts: new routes
must be reachable and new controls must use existing v3 tokens and primitives.

## Verification

Run focused tests for every conflict/new entry, full frontend Vitest, vue-tsc,
production build, and backend tests for version/update or other resolved backend
conflicts. Render desktop/mobile light/dark checks for GlobalNav, plugins, group
Fast/reasoning controls, accounts/quota, usage, model pricing, and Codex key
guidance. Check DOM, console, responsive containment, and keyboard reachability.

## Success Criteria

- Local main, origin/main, and v3 contain b1748c4ea or a newer fetched main.
- V3 has no obsolete sync merges and all listed features are reachable/styled.
- Focused/full tests, types, build, backend checks, and rendered QA pass.
- Remote v3 matches verified local v3 after a lease-protected push.
- All pre-existing untracked duplicate files remain byte-for-byte untouched.
